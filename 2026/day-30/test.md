
# Python Sample Code

```python
def greet(name):
    """A simple greeting function."""
    return f"Hello, {name}!"

def calculate_sum(numbers):
    """Calculate the sum of a list of numbers."""
    total = sum(numbers)
    return total

if __name__ == "__main__":
    # Example usage
    message = greet("World")
    print(message)
    
    nums = [1, 2, 3, 4, 5]
    result = calculate_sum(nums)
    print(f"Sum: {result}")
```
